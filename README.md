# 个人工作台

一个纯前端静态站点，数据默认保存在浏览器本地存储（localStorage）中。

## 在线访问

部署在 GitHub Pages：

## 功能

- 首页总览：打卡、待办、记账、身体数据等关键指标一览。
- 身体管理：体重、饮水、运动、饮食记录；饮水支持快捷预设、自定义水量（含负数）、明细折叠。
- 纪念日 / 人情台账 / 愿望清单 / 家人档案 / 猫咪档案。
- 财务：收支流水、账户、攒钱目标。
- 车辆：充电、加油记录与统计。
- 影剧书 / 备考 / 学习 / 日记 / 工作留痕。

## 数据说明

- 所有数据默认仅存于本机浏览器，刷新、关闭页面不会丢失。
- 清理浏览器缓存 / 卸载浏览器 / 无痕模式 / 换设备会导致数据丢失。
- 可在「设置 → 数据备份」中导出 JSON，或配置 WebDAV / GitHub Gist 自动备份。

## 本地运行

```bash
python3 -m http.server 8099
```

然后打开 http://localhost:8099 。
